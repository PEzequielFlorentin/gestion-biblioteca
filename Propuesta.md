# Propuesta de Proyecto: Catálogo y Gestión de Libros

## Descripción

El proyecto consistirá en desarrollar una aplicación web para la gestión y consulta de una biblioteca. El sistema permitirá a los usuarios registrados consultar un catálogo de libros, buscar ejemplares y visualizar información detallada de cada uno.

Además, contará con un usuario administrador encargado de gestionar el catálogo y mantener actualizada la información de los libros, autores y géneros.

## Funcionalidades principales

### Usuario final

* Registrarse e iniciar sesión.
* Consultar el catálogo de libros.
* Buscar libros por título.
* Filtrar libros por género.
* Consultar información detallada de cada libro.
* Solicitar el préstamo de un libro.
* Consultar sus préstamos.

### Administrador

* Iniciar sesión mediante su cuenta.
* Agregar nuevos libros.
* Modificar información de libros.
* Eliminar libros.
* Gestionar autores y géneros.
* Gestionar los préstamos realizados.

## Datos principales

El sistema contará con información relacionada con:

* Usuarios.
* Libros.
* Autores.
* Géneros.
* Préstamos.

## Objetivo

El objetivo del proyecto es desarrollar un sistema Full-Stack que permita aplicar los conocimientos adquiridos durante la cursada, implementando una API REST, persistencia de datos, autenticación y autorización de usuarios, y una interfaz web para interactuar con el sistema.
